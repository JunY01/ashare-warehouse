# 情绪回溯可行性尖峰（2026-09-10）

结论：股吧翻页回溯可行，建议回溯窗口≤2周；小红书无 Key 不可用。

## 实测（urllib + Chrome UA，串行+间隔2秒）

- 股吧列表页 `list,{board}[_{pg}].html`：第1/2/3/5/8页各返回约78条目，
  去重后每页全新增（overlap=0），翻页有效。
- 日期格式为 `MM-DD HH:MM`（如 `09-10 11:16`，需补年份；跨年时 12月帖归上一年），
  8页回溯到 `09-07`，约每天3页；2周约需40页，限流风险可控但需更慢。
- 日期标记为 `<span class="l5">`（span非cite），标题/阅读/回复/作者/日期
  可按行配对（`articleh normal_post` 行内 `l1/l2/l3/l4/l5`）。
- 新映射吧验证：`of512690`酒ETF鹏华77条 / `of159992`创新药ETF银华78条 /
  `of512710`军工龙头ETF富国78条，均存在；`of512780`实为京津冀ETF，已改用
  `of159992`（market_map.SOCIAL_SECTOR_MAP 已修正）。

## 不可行项

- 原 temp/mom-index 正则按 `cite.l5` 解析日期，命中0条，需按 span 重写。
- XHS 的 rnote API 无 Key（RNODE_API_KEY），Playwright 直连需登录态，
  本次尖峰不做；回溯与每日采集先只做股吧源，XHS 保持可选跳过。
- 股吧仅标题无正文，mom 分析器依赖 content 字段时效果打折；
  做法：情绪指数以标题信号为主，content 缺失记 source=title-only。

## 建议回溯策略

- 默认关闭回溯；`--backfill-days N`（N≤14）显式开启，串行+sleep，
  失败置空不硬扛；帖子按解析日期分桶到自然日（`MM-DD`→补年），
  15:05前当日桶记 provisional。
- 与每日积累两条腿：回溯只做一次性冷启动，日常靠每日增量攒 history。
