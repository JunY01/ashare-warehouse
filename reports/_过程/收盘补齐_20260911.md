# 09-11 收盘数据补齐过程说明（2026-09-14 执行，含盘前捕获与后续补漏）

## 背景

09-11（周五）盘中 14:35 跑了更新（快照/复盘），**收盘后没有跑全量 `update_data.py`**，
所以库里 09-11 的行最初全是 14:35 盘中值（收盘价、当日涨跌幅、主力净流入、成交额都偏）。
本次把 09-11 的收盘数据补齐，并顺带补了若干非日内管线的数据集。

## 为什么不直接跑 `update_data.py`

1. **东财榜单接口盘前重置**：`f3(当日%)`=0.0、`f62(主力净流入)`=`-`、`f104/f105(涨跌家数)`=0、
   `f128(领涨股)`=`-`；`f2(最新价)`/`f9(PE)`/`f20,f21(市值)`/`f109(20日%)`/`f160(60日%)` 仍为上一交易日收盘值。
2. **所有脚本按 `date.today()` 打标**：盘前跑会把 09-11 的值写成 09-14 的行（日期错标），K线分片用 `end=TODAY`。
3. **盘前窗口是关键约束**：腾讯行情在 09:25 后切成当日盘中值，东财榜单同样重置。
   补"前一交易日收盘"只有在**次日开盘前**这一个窗口内可做。
4. **K线端点限流**：`stock/kline/get` 对该 IP 先 HTTP=000（连接被拒）后 `rc=102`（频控），
   而 `fflow/daykline`、`clist`、`datacenter`、`push2ex` 一直正常 → 分路径限流，与 cookie 无关
   （本轮已从浏览器会话取新 cookie 写入 `config/em_cookie.txt`，该文件 gitignore）。
