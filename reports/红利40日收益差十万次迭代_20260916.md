# 红利 40 日收益差：十万次迭代与三选一（20260916）

**一句话**：这套"红利跑过头了就减、跌过头了就加"的规则**是真的，但比文章说的弱得多**——
九万多次随机取样里平均只赢买入持有 **+0.27%**（价格口径 +1.05%），
而且**把分红算进来以后基本归零**（-0.50%），因为择时空仓要放弃红利一年 4% 的票息。
它最大的用处是**纪律**（别在高潮时加仓、别在深跌时割肉），不是收益。
三只里**中证红利**可用，**中证红利低波动不能让这套规则碰**。

前情：`reports/红利40日收益差择时_20260916.md`（单样本回测）。本文是它的十万次迭代与结论收敛。

## 1. 迭代怎么跑的

`research/sweep100k_red40.py`，92,543 组有效样本（回合不足 6 笔丢弃 7,457），随机取样维度：

| 维度 | 取值 |
|---|---|
| 红利指数 | 中证红利 / 上证红利 / 中证红利低波动（各约 3.1 万组） |
| 买入分位 | 10 / 15 / 20 / 25 / 30 / 35 / 40 / 45 % |
| 卖出分位 | 60 / 65 / 70 / 75 / 80 / 85 / 90 / 95 % |
| 分位口径 | 扩张窗口（只用截止当日历史，**可实盘**）／全样本（文章口径，含未来） |
| 卖点触发后仓位 | 清仓（0 仓）／减半（半仓） |
| 初始状态 | 满仓 / 空仓 |
| 时间窗 | 起点随机、跨度随机 750 日 ~ 全部（3~13.6 年） |

大盘基准固定国证A指（全市场，≈Wind全A）；空仓按货币基金 1.2%/年；含分红口径按各指数股息率
（中证红利 4.22%、上证红利 3.94%、红利低波 4.33%）逐日计提。

## 2. 六条从迭代里学到的结论

**① 规则是真的，但弱到接近随机。** 全体平均超额 **+0.27%**、中位 +0.36%、正超额占比 **58.9%**。
不是"年化超额 3%"那种故事——文章那个数字来自特定的强红利区间，换个样本就没有了。

**② 可实盘口径几乎不缩水 → 不是过拟合出来的。** 扩张分位（只用历史）+0.25% vs
全样本分位（含未来）+0.29%，只差 0.04pp。说明这条规律本身存在，只是**很小**。

**③ 票息决定成败：算上分红，超额变负。** 价格口径 **+1.05%** → 含分红口径 **-0.50%**。
机制清楚：卖点触发后你在场外，红利一年 4.2% 的票息照发，你只拿 1.2% 的现金息，
平均 1.9 次/年的进出、每次空仓约 2 个月，一年白丢 1.45%——比择时赚的那点还多。

**④ "上宽下窄"被系统性证实，而且比文章更极端。** 卖点分位从 60% 提到 95%，
平均超额单调抬升（-0.41% → +0.94%，正超额 42% → 76%）；买点太严反而害事
（买 10% 分位 -0.88%，买 15%~45% 全为正）。**别卖太早、别等太深。**

**⑤ "减仓不清仓"能把票息亏损救回来一半。** 这是本次迭代最有价值的发现：

| 口径（可实盘） | 卖点清仓 | 卖点减半 |
|---|---|---|
| 含分红·全体 | -0.84%（正超额 34.9%） | **-0.23%**（43.2%） |
| 含分红·中证红利 | -0.03%（49.1%） | **+0.19%**（58.9%） |
| 含分红·上证红利 | -0.56%（37.6%） | -0.09%（46.7%） |
| 含分红·红利低波 | -1.95%（17.6%） | -0.80%（23.6%） |

→ **满仓↔空仓二元切换是错误的用法**；底仓吃息、只用信号做边际调减，才是这套指标的活法。

**⑥ 状态依赖很重，别当全天候规则。** 按窗口起点分：2015 年起点 +0.75%（70% 正）、
2016 年起点 **-0.55%**（39.5% 正）、2020/2021 年起点 +0.66%/+1.02%。
按终点分：2020 年 **-0.50%**、2021 年 -0.35%。削顶检验：去掉 2015 年后全体超额从 +0.27%
掉到 +0.15%——**结论对样本年份敏感，是个边际信号，不是铁律**。

## 3. 三选一：推荐中证红利

| | 中证红利 sh000922 | 上证红利 sh000015 | 中证红利低波动 csH30269 |
|---|---|---|---|
| 规则平均超额（迭代） | **+0.79%**（70.1% 正） | +0.43%（63.4% 正） | -0.40%（43.1% 正） |
| 含分红·减半·可实盘 | **+0.19%** | -0.09% | -0.80% |
| 与已有银行持仓重叠 | **0.68**（最低） | 0.71 | 0.75（最高） |
| 估值 PB 分位 | **50.0%**（最便宜） | 62.7% | 62.0% |
| 估值 PE 分位 | 79.8% | 96.8%（最高） | 78.9% |
| 股息率 | 4.22% | 3.94% | 4.33% |
| 含分红年化（2013-12至今） | **11.95%** / 夏普 0.51 | 9.72% / 0.41 | 11.88% / 0.53 |
| 当前 40 日收益差分位 | 56.9%（离买点 2.1pp） | 70.6%（离卖点仅 3.1pp） | 55.1% |

- **选中证红利**：规则在它身上最有效、与银行重叠最低（好哥哥已持中证银行）、PB 分位最低、
  当前位置最中性（离买卖两边都还有空间）。
- **不选上证红利**：规则样本分布里它上限最高（(30%,90%) 那档 +2.97%/91% 正），但那是筛出来的；
  含分红口径优势消失，且现在 70.6% 分位+PE 96.8% 分位买它等于追高。
- **不选红利低波**：三种口径下这套规则在它身上**全部为负**（含分红减半 -0.80%、正超额仅 23.6%）、
  与银行重叠最高、PB 分位也不低。⚠️ 注意区分两件事：持仓引擎的结论是 **HOLD=不动**
  （如果还在手里就不该卖）；而"已经卖了要不要买回来"是**新决定**，这里的证据说**不买回**。

## 4. 具体怎么用（可执行）

标的：跟踪**中证红利（000922）**的场外指数基金（或场内 515080/515180 一类）。

| 动作 | 触发（40 日收益差） | 用法 |
|---|---|---|
| 首次建仓/加半 | ≤ **-1.5%**（40% 分位） | 先买计划额的一半 |
| 加满 | ≤ **-4.6%**（20% 分位） | 补另一半 |
| 减 1/3 | ≥ **+4.8%**（85% 分位） | **不清仓**（清仓式择时在含分红口径下是负的） |
| 再减 1/3 | ≥ **+6.5%**（90% 分位） | 留 1/3 底仓长期吃息 |

底线规则：**底仓不动吃票息**，收益差只用来做边际调增减；估值两把尺子（PB 分位）与
收益差打架时不动。现在四条线都在区间中部，**当前动作 = 不动**。

## 6. 分几次买、卖点减多少：同窗配对检验（2026-09-16 补）

前面第 5 节是池化平均，窗口差异会把买卖档位的差别淹没（同一套方案在 3 年窗口和 12 年窗口里
表现天差地别）。所以补一层**同窗配对**：固定 5000 个随机窗口，每个窗口里把所有方案各跑一遍，
再逐窗比较——只留方案差异，去掉窗口差异。全部为含分红口径、扩张分位、中证红利单只。

**买法**（卖法固定"85→半仓/90→1/3"）：

| 对比 | 差值 | 前者更好的窗口占比 |
|---|---|---|
| 两档(40→半仓/20→满仓) vs 一次买满(40→满仓) | **+0.28pp/年 ±0.01** | 61% |
| 三档(40/30/20) vs 两档(40/20) | -0.02pp/年 ±0.002 | 26% |

→ **分两次买最好；分三次没有额外好处（反而略差）；一次买满明显差。**

**卖法**（买法固定两档）：

| 对比 | 差值 | 前者更好的窗口占比 |
|---|---|---|
| 到 85% 分位减仓 vs 不减仓 | **+0.47pp（初始满仓）/ +0.74pp（初始空仓）** | 70% / 82% |
| 第一次减到半仓 vs 只减到 2/3 | +0.13pp/年 | 71% |
| 第二次减到 1/3 vs 清空 | **+0.26pp/年**（清仓只在 31% 窗口更好） | 69% |
| 分两档减 vs 一次清仓 | ±0.04pp（打平） | 51~57% |

→ **到了卖点要减（比不减每年多 0.5~0.7pp，回撤从 -27.7% 改善到 -21.5%）；第一次减到半仓、
第二次减到 1/3 并留底仓；「减多少」本身差异很小，不必纠结。**

修正一处此前的说法：第 5 节说"卖点只能减仓不能清仓、清仓式择时含分红口径为负"，
那是池化平均被窗口噪声放大的结果。**同窗配对下清仓与减半打平**（±0.04pp），真正的分界是
"减 vs 不减"，不是"清仓 vs 减半"。留 1/3 底仓的理由来自"第二次减到 1/3 比清空多 0.26pp"，
以及现实里 9-14 那次误判清仓的教训。

**定档后的阶梯（已写进 E区 `red40_monitor.py`）**：

```
买点1 ≤40%分位 → 建到半仓      卖点1 ≥85%分位 → 减到半仓（减掉一半）
买点2 ≤20%分位 → 买满         卖点2 ≥90%分位 → 再减到 1/3（永久留 1/3 底仓）
中间区（40%~85%）→ 不动仓位
```

复现：`python research/sweep100k_red40.py --grid --windows 2000`（配对检验脚本见提交记录）。
