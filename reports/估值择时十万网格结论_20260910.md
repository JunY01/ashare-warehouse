# 估值择时十万网格迭代 —— 结论报告

> 生成 2026-09-10 ｜ 网格 **115,200 组** ｜ 可回测指数 11 个 ｜ 月度调仓
> 数据区间：多数指数 2016-09 ~ 2026-08（9.7年）
> 脚本：`research/sweep100k_valuation.py` ｜ 结果：`data/cache/sweeps/sweep100k_valuation.jsonl`

---

## 〇、先说数据边界（诚实声明）

用户要求"结合市场行情/情绪/庄家思维"。**能做和不能做的必须先分清：**

| 数据 | 历史长度 | 能否回测 |
|---|---|---|
| 估值 PE/PB（蛋卷周频） | 10 年 | ✅ 能 |
| 价格 OHLC | 10~20 年 | ✅ 能 |
| 行情 regime（价/MA/回撤自算） | 10~20 年 | ✅ 能 |
| **市场情绪（社群 mom/dad 双指数）** | **仅 3 个月**（2026-06 起） | ❌ **不能** |
| **庄家资金流（sector_flow_daily）** | **仅 6 个月**（2026-03 起） | ❌ **不能** |

**所以本轮 115,200 组网格只覆盖"估值+行情"两轴。情绪与庄家数据不进网格——用 3~6 个月数据做过拟合，等于自欺。** 这两项只能作为"当前状态"参考（见第五节），不能声称"回测验证过"。

---

## 一、网格设计

| 维度 | 取值 | 数量 |
|---|---|---|
| 判据 | PE / PB | 2 |
| 分位窗口 | 3 / 5 / 7 / 10 年 | 4 |
| 买入分位 | ≤10/20/30/40/50% | 5 |
| 卖出分位 | ≥60/70/80/90% | 4 |
| 行情过滤 | 无 / 价>MA / 价<MA / MA上行 / MA下行 | 5 |
| MA 周期 | 100/150/200/250 | 4 |
| 建仓力度 | 0.5x / 1.0x / 2.0x | 3 |
| 缓冲(pp) | 0 / 5 / 10 | 3 |
| 止损 | 0 / -10 / -15 / -20% | 4 |

合计 115,200 组，每组在 11 个指数上独立回测，用**跨指数中位数**打分（防单指数过拟合）。

---

## 二、最重要的结论：这套方法跑不赢买入持有

| 指标 | 结果 |
|---|---|
| 总组数 | 115,200 |
| **超额收益 > 0 的组** | **29,416（25.5%）** |
| 超额 > 3% 的组 | 1,426（1.2%） |
| **整体平均超额** | **-1.19%** |
| 各指数买入持有年化中位 | **5.9%** |

**四分之三的策略跑不赢什么都不做。** 这不是参数没调好——是**估值分位择时本身提供的信号很弱**。

### 按判据/窗口看平均超额（全负）

| 判据·窗口 | 平均超额 |
|---|---|
| PB 10年 | **-0.38%**（最好） |
| PB 5/7年 | -0.50% |
| PB 3年 | -1.18% |
| PE 5年 | -1.53% |
| PE 10年 | -1.59% |
| PE 3年 | -2.10% |

**PB 普遍优于 PE**（这修正了我之前手拍"看PE"的判断），但**全都跑输买入持有**。

### 按行情过滤看平均超额

| 行情过滤 | 平均超额 |
|---|---|
| 价<MA（弱市才持有） | **-0.09%**（最好） |
| MA上行 | -0.94% |
| 无过滤 | -0.97% |
| MA下行 | -1.48% |
| **价>MA（强市才持有）** | **-2.46%（最差）** |

**"只在价格站上均线时持有"是最差的过滤方式**——恰恰是散户追涨的做法，数据上被证伪。

## 三、样本外检验：没有参数可靠

把区间切成前后两半，对 115,200 组分别算前后半超额：

**前半超额 与 后半超额 的相关系数 = 0.104**

**接近零。** 意味着：**在这半段表现好的参数，到下半段基本不能重现。** 任何"挖出来的最优参数"都是样本内噪声。

按全样本超额挑出的 TOP10，无一例外都是"前半 -11%、后半 +5%"——**结论完全由区间决定，不是由策略有效性决定**。

---

## 四、那它到底有没有用？有——但作用不是赚钱，是降波动

既然跑不赢收益，检验用户真正在意的目标（"少亏优先"）：规则"分位<X 则满仓、否则空仓" vs 买入持有：

| 规则 | 策略年化 | 策略回撤 | 买持年化 | 买持回撤 | **回撤改善** |
|---|---|---|---|---|---|
| PE 10年 买<20% | 2.3% | -32.4% | 2.5% | -45.7% | **+13.2pp** |
| PE 10年 买<30% | 3.3% | -36.0% | 2.5% | -45.7% | **+9.7pp** |
| PB 10年 买<20% | 2.9% | -35.0% | 2.5% | -45.7% | **+10.7pp** |
| PB 10年 买<30% | 1.6% | -36.9% | 2.5% | -45.7% | +8.7pp |

**结论：估值分位能把最大回撤砍掉 8~13 个百分点，收益基本持平（甚至略低）。**

**它是"减震器"，不是"发动机"。** 用它换来的是"少亏"，代价是"少赚"——这恰好匹配用户"少亏优先、回撤10%内"的设定。

## 六、给用户的诚实结论

1. **我不会再靠"分位读数"单点下判断。** 十万次迭代证明：那套方法 74.5% 的概率跑输什么都不做，且参数在样本外不可重现（相关 0.10）。

2. **估值分位的正确用法是"控制仓位上限、降低回撤"，不是"择时赚钱"。** 用"高分位不重仓、低分位才重仓"的纪律，历史回撤可砍 8~13pp。

3. **当前状态**：全市场只有**恒生科技 PB 19%** 落在"持有区"；银行(92%)、红利(97%)、科创50(83%)、中证500(80%) 都在高位，**按回测支持的口径是"不新增、可减"**。但注意：这个"可减"的信号强度有限（因为它本质上不能预测收益，只能控制风险敞口）。

4. **中证A500 无估值数据**，任何关于它的建议都是无依据的——这一条保持不变。

5. **情绪与庄家数据不可回测**，我不会拿它们给"经过验证"的建议。它们目前只能说明：**老手（爸爸指数）活跃度明显高于新手**，这种结构在历史上多见于"存量博弈"而非"增量入场"。
